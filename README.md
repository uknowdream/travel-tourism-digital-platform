# Travel & Tourism Digital Platform

A responsive travel and tourism website portfolio showcasing destination discovery, curated trip packages, and an accessible mobile-first browsing experience.

## Features
- Responsive desktop and mobile navigation
- Destination and trip-style filtering
- Favorite destinations stored in browser storage when available
- Accessible controls and reduced-motion-aware interactions
- Responsive destination and package cards with lazy-loaded imagery
- SEO and Open Graph metadata

## Run locally
Open `index.html` in a modern browser. Google Fonts and Unsplash images require an internet connection.

## Quality checks
Requires Node.js 20 or newer. Run `npm test` to execute lightweight static checks. These checks do not replace browser-based end-to-end, accessibility, or cross-device testing.

## Demo limitations
This is a portfolio/demo project, not a live travel agency. Prices, reviews, testimonials, and statistics are illustrative. No backend, booking engine, payment gateway, customer accounts, or CRM is connected. Inquiry and newsletter actions may be demo-only.

## Deployment
This is a static website suitable for GitHub Pages, Vercel, or another static host. Configure the host to serve the repository root; no build command is required for the current static implementation.

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript · Node.js built-in test tooling

## Source
Based on the `travel-porto` project, copied into a separate repository. The original repository remains unchanged.
